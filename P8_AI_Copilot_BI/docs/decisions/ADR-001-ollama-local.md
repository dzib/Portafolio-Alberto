# ADR 001: Uso de Ollama para IA Local

        - **Contexto:** Se requiere procesamiento de lenguaje natural sin
            incurrir en costos de nube (APIs de OpenAI/Anthropic).
    - **Decisión:** Implementar Ollama con Llama 3.2 para ejecución offline.
        - **Consecuencia:** Privacidad absoluta de los datos y coste
            operativo de 0 USD.
