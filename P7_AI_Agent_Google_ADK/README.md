# Agent Valley Night Market

## Overview

Conversational AI agent developed using Google Agent Development Kit (ADK),
Vertex AI and Gemini Live.

## Architecture

```mermaid
flowchart TD

A[User] --> B[Web Interface]

D --> E[Vertex AI]

E --> F[Gemini Live]

F --> G[Voice Response]
F --> H[Text Response]
```
