# ADR-002: Integración de Gemini Live para Interacciones de Audio Nativo

* **Estado:** Aceptado
* **Contexto:** Para cumplir con el requerimiento de una experiencia de
  usuario conversacional fluida y de baja latencia, se buscó evitar la
  fricción y el desfase temporal de los pipelines tradicionales de conversión
  de voz a texto y texto a voz por separado.
* **Decisión:** Implementar **Gemini Live (Audio Nativo)** mediante Vertex AI
  para soportar capacidades conversacionales bidireccionales en tiempo real
  tanto en voz como en texto.
* **Consecuencias:**
  * **Positivas:** Ofrece una experiencia de usuario natural, reduce
    drásticamente la latencia de respuesta y aprovecha las capacidades
    multimodales nativas del modelo.
  * **Negativas:** Requiere conexiones de red estables y un monitoreo riguroso
    de los flujos de streaming en tiempo real.
