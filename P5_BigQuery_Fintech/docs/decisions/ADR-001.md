# ADR-001: Adopción de Google Cloud BigQuery para Analítica Financiera

## 📅 Estado

Aprobado y en Producción

## 📌 Contexto

Se requiere procesar y consolidar un volumen masivo de datos
transaccionales de préstamos (~1.2 millones de registros) garantizando
costos controlados y alta disponibilidad sin mantenimiento de
infraestructura de servidores.

## 🎯 Decisión

Adoptar **Google Cloud BigQuery** como motor analítico central y
almacenamiento columnar serverless, utilizando consultas `CTAS`
idempotentes para la agregación de datos por año (`issue_year`).

## ⚖️ Consecuencias

- **Positivas:** Desacoplamiento total del cómputo y almacenamiento,
  reducción de costos de escaneo y eliminación de la administración de
  clústeres.
- **Negativas:** Curva de aprendizaje en la optimización de costos por
  consultas mal estructuradas (mitigada mediante pruebas unitarias de
  validación).
