# Dependencias Técnicas - Módulo P6

* **Entorno de Ejecución:**
  * Python versión 3.11.x optimizado para la compatibilidad con Airflow.
* **Gestor de Paquetes:**
  * `uv` para la resolución y rápida instalación de dependencias en
    entornos virtuales aislados (`.venv`).
* **Librerías Clave del Pipeline:**
  * `apache-airflow==2.10.2` (motor de orquestación).
  * `pandas` y librerías de soporte para procesamiento analítico.
  * `psycopg2-binary` para la conectividad con PostgreSQL.
