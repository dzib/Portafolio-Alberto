# ADR-001: Adopción de Apache Airflow como Motor de Orquestación

* **Estado:** Aceptado
* **Contexto:** El proyecto requiere automatizar y coordinar la ejecución
  secuencial de tareas ETL, asegurando tolerancia a fallos, reintentos
  automáticos, trazabilidad de ejecuciones y un monitoreo visual centralizado.
* **Decisión:** Se adopta **Apache Airflow (Versión 2.7.2)** como la
  plataforma estándar de orquestación basada en código (*DAGs as Code* en
  Python).
* **Consecuencias:**
  * **Positivas:** Permite definir dependencias complejas de manera
    declarativa, gestionar reintentos resilientes mediante parámetros nativos
    y provee una interfaz gráfica robusta para la auditoría operativa.
  * **Negativas:** Introduce una sobrecarga de infraestructura inicial al
    requerir una base de datos relacional para la gestión de metadatos.
