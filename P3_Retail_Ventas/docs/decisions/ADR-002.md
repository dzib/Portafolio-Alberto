# ADR-002: Uso de Vistas SQL Nativas para Consumo Híbrido en Python

## Estado

Aceptado

## Contexto

El sistema Python requería consumir los datos procesados y normalizados en SQL
Server para generar reportes analíticos y dashboards de consola en tiempos
menores a un segundo.

## Decisión

Se decidió materializar la lógica de negocio y los reportes mediante vistas
relacionales optimizadas en SQL Server, consumidas directamente desde los
scripts de Python mediante consultas livianas.

## Consecuencias

- **Positivas:** Desacopla la lógica analítica pesada del código de
  aplicación en Python, aprovechando la potencia del motor de base de datos
  para obtener respuestas sub-segundo (`0.53s`).

- **Negativas:** Requiere mantener sincronizados los esquemas de las vistas
  ante cualquier modificación estructural en las tablas base.
