# ADR-001: Integración de SQLAlchemy con fast_executemany para ingestión masiva

## Estado

Aceptado

## Contexto

El proyecto requiere ingerir un volumen sintético de 50,000
transacciones desde Python hacia SQL Server 2025 en un tiempo récord,
evitando cuellos de botella por inserciones fila por fila
(*row-by-row insert*).

## Decisión

Se implementó SQLAlchemy configurado con el parámetro
`fast_executemany=True` sobre el controlador ODBC Driver 17,
permitiendo transferencias masivas en lotes optimizados.

## Consecuencias

- Positivas: Permite alcanzar tasas de transferencia de ~27,000
  registros por segundo, completando la carga de 50,000 registros en
  menos de 2 segundos.
- Negativas: Requiere asegurar que los tipos de datos en el DataFrame
  de pandas coincidan estrictamente con el esquema DDL de destino.
