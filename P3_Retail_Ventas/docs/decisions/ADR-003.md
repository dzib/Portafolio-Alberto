# ADR-003: Resolución de Colisiones en Unique Keys mediante Agregación

## Estado

Aceptado

## Contexto

Durante el proceso de ingesta masiva y transformación ETL en entornos de comercio
 minorista (*Retail*), las variaciones de precios o metadatos en el origen pueden
 generar violaciones de restricciones de unicidad (*Unique Key / Primary Key*).

## Decisión

Implementar lógica de agregación estricta utilizando funciones como `MAX()` y
 agrupamiento por `GROUP BY` directamente en la fase de carga y limpieza SQL.

## Consecuencias

Se garantiza la integridad referencial absoluta, evitando errores de duplicidad
 y asegurando que las vistas analíticas consuman datos limpios y consistentes.
