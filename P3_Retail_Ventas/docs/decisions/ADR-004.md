# ADR-004: Trazabilidad y Aislamiento de Métricas mediante Lotes (GO)

## Estado

Aceptado

## Contexto

Durante el procesamiento de operaciones masivas, la pérdida de contexto
 en variables del sistema como `@@ROWCOUNT` tras instrucciones DDL dificulta
 la medición exacta del impacto transaccional.

## Decisión

Estratificar la ejecución de scripts utilizando el comando `GO` para separar
 lotes y capturar de manera inmediata las métricas de filas afectadas y
 tiempos en milisegundos.

## Consecuencias

Garantiza una observabilidad absoluta del rendimiento del pipeline, facilitando
 la detección de cuellos de botella y la comunicación de resultados ejecutivos.
