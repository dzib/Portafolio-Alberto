# Objetivo

Analizar 50,000 transacciones retail simuladas.

## Stakeholders

Gerencia Comercial
Operaciones
Finanzas

## Necesidades

Ventas
Margen
Rotación
Ticket promedio

## Alcance

El proyecto analiza ventas retail simuladas para identificar
tendencias comerciales, desempeño por producto y métricas
clave para la toma de decisiones.

## Criterios de éxito

- Dashboard funcional
- KPIs calculados correctamente
- Dataset validado
