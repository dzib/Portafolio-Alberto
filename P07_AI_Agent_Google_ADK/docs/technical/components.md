# Componentes Técnicos - Módulo P7

* **FastAPI Backend:**
  * Servidor web de alto rendimiento encargado de recibir y enrutar las
    solicitudes de los usuarios e interactuar con el sistema de agentes.
* **Google Agent Development Kit (ADK):**
  * SDK principal que provee el framework de orquestación de agentes,
    gestión de estados conversacionales y ejecución dinámica de herramientas.
* **Vertex AI (Gemini Live):**
  * Plataforma en la nube de Google Cloud que hospeda el modelo multimodal
    avanzado capaz de procesar audio nativo en tiempo real.
* **Script de Aprovisionamiento (`setup_project.sh`):**
  * Automatizador de infraestructura para la habilitación de APIs,
    configuración de permisos y validación de conectividad en el proyecto.
