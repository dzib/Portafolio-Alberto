# Dependencias Técnicas - Módulo P7

* **Entorno de Ejecución:**
  * Python versión 3.12.x optimizado para la compatibilidad con el
    ecosistema de IA.
* **Gestor de Paquetes:**
  * `uv` para la resolución y rápida instalación de paquetes en entornos
    virtuales aislados.
* **Librerías Clave del Ecosistema:**
  * `google-adk` (framework de desarrollo de agentes).
  * `google-genai` (SDK oficial para modelos Gemini).
  * `fastapi` y `uvicorn` (servidor y framework de APIs).
