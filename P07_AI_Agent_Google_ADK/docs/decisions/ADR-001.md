# ADR-001: Adopción de Google Agent Development Kit (ADK) y Vertex AI

* **Estado:** Aceptado
* **Contexto:** El proyecto requiere construir un agente conversacional
  inteligente capaz de orquestar flujos de trabajo autónomos, gestionar estados
  de sesión y realizar llamadas a herramientas sobre la infraestructura de
  Google Cloud.
* **Decisión:** Se adopta **Google Agent Development Kit (ADK)** en conjunto
  con **Vertex AI** como el framework y backend estándar para el desarrollo y
  despliegue del agente de IA.
* **Consecuencias:**
  * **Positivas:** Proporciona abstracciones nativas para la orquestación de
    agentes, manejo de flujos conversacionales complejos y una integración
    sumamente fluida con los modelos Gemini.
  * **Negativas:** Introduce una dependencia estricta con el ecosistema de
    Google Cloud Platform y la disponibilidad de sus servicios administrados.
