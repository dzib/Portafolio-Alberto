# Requerimientos de Negocio - Módulo P7 (Agente de IA y Google ADK)

* **BR-01: Experiencia Conversacional en Tiempo Real**
  * El sistema debe proveer una interfaz conversacional fluida y de
    baja latencia utilizando las capacidades de audio nativo de Gemini Live
    para interacciones naturales con los usuarios.
* **BR-02: Orquestación Autónoma con Google ADK**
  * Se requiere un núcleo de agentes impulsado por Google Agent
    Development Kit (ADK) para gestionar estados de sesión, flujos de
    trabajo y la ejecución dinámica de herramientas de software.
* **BR-03: Integración Segura con Cloud Backend**
  * La arquitectura debe conectarse de forma segura con los servicios de
    Vertex AI en Google Cloud Platform, gestionando adecuadamente la
    autenticación y credenciales de la aplicación.
