# ADR-002: Selección de Google Cloud BigQuery para Analítica Fintech

## Contexto

Se requiere procesar y almacenar grandes volúmenes de datos
transaccionales y financieros del Proyecto P5 con tiempos de
respuesta óptimos y sin sobrecargar la infraestructura local de
SQL Server 2025.

## Decisión

Utilizar Google Cloud BigQuery como motor de Data Warehousing
analítico en la nube para consultas serverless y agregaciones
masivas.

## Alternativas Consideradas

- Mantener todo el almacenamiento históricamente en bases de datos
  relacionales locales (SQL Server).
- Desplegar instancias dedicadas de PostgreSQL en servidores
  virtuales cloud.

## Consecuencias

- Positivas: escalabilidad alta, procesamiento analítico inmediato y
  costos optimizados por consulta basada en volumen procesado.
- Negativas: dependencia directa del proveedor de infraestructura en
  la nube (GCP).
