# ADR-003: Automatización de Calidad de Datos mediante CI/CD y Pytest

## Contexto

Para garantizar que el portafolio mantenga un estándar de producción listo
para auditoría, es indispensable evitar regresiones o enlaces rotos en la
documentación y fallos lógicos en los pipelines.

## Decisión

Integrar pruebas unitarias automatizadas con **Pytest** y flujos de
integración continua en **GitHub Actions** (`ci.yml`), acompañados de
scripts de validación de enlaces en Markdown.

## Alternativas Consideradas

- Pruebas manuales posteriores a cada modificación de repositorio.
- Validación local sin integración en el servidor remoto de GitHub.

## Consecuencias

- **Positivas:** Trazabilidad absoluta, garantía de 0 enlaces rotos en todo el
  portafolio y confianza técnica para evaluadores y reclutadores.
- **Negativas:** Requiere tiempo inicial de configuración de los workflows de
  automatización.
