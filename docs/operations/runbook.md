## 📖 Runbook Operativo

Procedimientos estándar para la resolución rápida de incidencias operativas:

### Fallos comunes

- **Fallo de Conexión ODBC:** Verificar el estado del servicio SQL Server
 local y la correcta version del Driver ODBC instalado.
- **Conflictos de Dependencias en Python:** Reactivar el entorno virtual
 (`.venv`) y reincidir la instalación limpia desde los requerimientos del
 proyecto.
- **Recuperación Ante Desastres (Recovery & Reset):** Protocolo de
 reconstrucción de bases de datos y reconfiguración de rutas en caso de
 fallos críticos del entorno de desarrollo.
