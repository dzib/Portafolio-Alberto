# 🏷️ Convenciones de Nomenclatura

Para asegurar la legibilidad y estandarización a lo
largo de todo el portafolio:

- **Bases de Datos y Tablas (SQL Server):** Utilizar
  `snake_case` en minúsculas (ej. `dim_clientes`,
  `fact_ventas_diarias`).
- **Procedimientos Almacenados y Funciones:** Prefijo
  descriptivo en `PascalCase` o `snake_case`
  normalizado (ej. `sp_calcular_inventario`).
- **Scripts de Python:** Nombres en `snake_case`
  descriptivos (ej. `ingesta_pipeline.py`,
  `audit_portfolio.py`).
- **Ramas de Git (Git Flow):**
  - Producción: `main`
  - Integración: `develop`
  - Características: `feature/<nombre-de-la-caracteristica>`
