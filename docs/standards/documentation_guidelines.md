# 📖 Guías de Documentación y Calidad Markdown

Toda la documentación técnica del portafolio debe cumplir con los siguientes criterios:

1. **Cero Enlaces Rotos:** Todo hipervínculo interno o externo debe ser
    verificado mediante el script de auditoría
    (`tools/audit_portfolio.py`).
2. **Uso de Diagramas:** Se fomenta el uso de sintaxis `mermaid` para
    ilustrar diagramas de arquitectura y flujos ETL de manera visual.
3. **Estructura Clara:** Uso obligatorio de encabezados jerárquicos (`##`,
    `###`), tablas comparativas y bloques de código con su respectivo
    lenguaje especificado.
