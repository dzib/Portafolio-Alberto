# ADR-002: Uso de DBCC CHECKIDENT para Repetibilidad en Pruebas de Estrés

## Estado

Aceptado

## Contexto

Durante la ejecución de las pruebas de estrés (_Stress Testing_),
la inserción masiva y borrado repetido de registros causaba
desalineación en los contadores `IDENTITY`, rompiendo las
llaves foráneas dependientes.

## Decisión

Se estandarizó el uso mandatorio de
`DBCC CHECKIDENT ('Tabla', RESEED, 0)` en los scripts de
inicialización y pruebas para garantizar que cada simulación
parta desde una base limpia y predecible.

## Consecuencias

- **Positivas:** Garantiza la repetibilidad absoluta de los
  escenarios de prueba y previene errores de integridad
  referencial.
- **Negativas:** Ninguna relevante en entornos de desarrollo y
  pruebas.
