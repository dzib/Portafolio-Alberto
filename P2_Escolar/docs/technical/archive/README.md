# Experimental Artifacts

## Propósito

Esta carpeta conserva artefactos de ingeniería utilizados durante las
fases de investigación, optimización y validación del proyecto.

Los archivos almacenados aquí no forman parte del pipeline productivo,
pero representan evidencia del proceso de diseño, análisis y mejora
continua aplicado durante el desarrollo.

---

## Contenido

### temp_modify.py

Script auxiliar utilizado para pruebas de refactorización y modificación
automatizada sobre configuraciones del Stress Test.

### temp_parse_test.sql

Script de experimentación para análisis y validación de procesos de
parseo y extracción de información.

### temp_stress_fast.sql

Versión optimizada del Stress Test utilizada durante pruebas de
rendimiento y tuning de carga masiva.

---

## Justificación Arquitectónica

Mantener estos artefactos documentados permite:

- Preservar trazabilidad técnica.
- Documentar decisiones de optimización.
- Evidenciar capacidades de troubleshooting.
- Facilitar auditorías futuras.
