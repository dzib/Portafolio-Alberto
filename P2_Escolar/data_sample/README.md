# Data Sample

## Descripción

El proyecto utiliza datos sintéticos generados mediante procesos
determinísticos para simular un entorno académico institucional
educativo de nivel superior.

Generamos los registros con datos sintéticos con el
objetivo de garantizar repetibilidad y consistencia en escenarios de
Stress Testing, ETL y Business Intelligence

---

## Entidades Simuladas

### Catálogos

- Departamentos
- Carreras
- Profesores

### Operaciones

- Alumnos
- Materias
- Inscripciones
- Calificaciones
- Asistencias

---

## Objetivo

Permitir pruebas repetibles de:

- Stress Testing
- Integridad Referencial
- ETL
- Calidad de Datos
- Analítica

---

## Casos de Uso

Los datos permiten validar:

- Integridad referencial.
- Cargas masivas.
- Procesos ETL.
- Calidad de datos.
- Reportes analíticos.
- Dashboards ejecutivos.

---

## Consideraciones

Todos los registros son sintéticos.

No contienen información real, personal o sensible (PII o PHI).
