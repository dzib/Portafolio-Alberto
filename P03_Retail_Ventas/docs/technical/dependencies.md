# 📦 Dependencias y Entorno Tecnológico - P3

## 🐍 Entorno Python (3.13)

- **pandas**: Manipulación y análisis de estructuras de datos tabulares en memoria.
- **sqlalchemy**: Capa de abstracción de bases de datos y conexión ORM con el
 motor relacional.
- **Faker**: Generación sintética y estocástica de datos de transacciones comerciales.
- **pyodbc**: Conectividad nativa por medio del driver ODBC 17 para SQL Server.

## 🗄️️ Entorno SQL Server 2025

- **Motor Transaccional T-SQL**: Administración de esquemas, constraints de
 unicidad y CTEs.
- **SQL Server Management Studio (SSMS 22)**: Interfaz de gestión y ejecución
 de scripts secuenciales.
