# ADR-001: Integración de SQLAlchemy con fast_executemany para ingestión masiva

## Implementación de Arquitectura Híbrida (Python + SQL Server 2025)

## Estado

Aceptado

## Contexto

El proyecto requiere ingerir un volumen sintético de (50,000+)
transacciones desde Python hacia SQL Server 2025 en un tiempo récord,
evitando cuellos de botella por inserciones fila por fila
(*row-by-row insert*). Garantizando velocidad en la generación sintética
 y robustez transaccional en el almacenamiento.

## Decisión

Se implementó SQLAlchemy configurado con el parámetro
`fast_executemany=True` sobre el controlador ODBC Driver 17,
permitiendo transferencias masivas en lotes optimizados.
Utilizar Python (`Faker`, `Pandas`) como motor de orquestación
 y generación estocástica, integrándolo mediante SQLAlchemy
 y ODBC Driver 17 con SQL Server 2025 para la persistencia masiva.

## Consecuencias

- *Positivas:* Permite alcanzar tasas de transferencia de ~27,000
  registros por segundo, completando la carga de 50,000 registros en
  menos de 2 segundos.
  - Mejora en la mantenibilidad del código, ya que se separa la lógica de
   negocio de la lógica de acceso a datos.
  - Mejora en la escalabilidad del sistema, ya que se puede manejar un mayor
   volumen de datos sin afectar el rendimiento.
  - Mejora en la calidad del código, ya que se utiliza una arquitectura más
   limpia y mantenible.
  - Mejora en la productividad del equipo, ya que se reduce el tiempo necesario
   para realizar cambios y mantenimiento.
  - Mejora en la experiencia del usuario, ya que se proporciona un servicio más
   rápido y confiable.
  - Mejora en la seguridad del sistema, ya que se implementa una arquitectura
   más robusta y segura.
  - Mejora en la eficiencia del desarrollo, ya que se reduce el tiempo necesario
   para implementar nuevas funcionalidades.
  - Mejora en la claridad de la arquitectura, ya que se separan claramente las
 responsabilidades entre el procesamiento en memoria y la capa relacional.

- *Negativas:* Requiere asegurar que los tipos de datos en el DataFrame
  de pandas coincidan estrictamente con el esquema DDL de destino.
