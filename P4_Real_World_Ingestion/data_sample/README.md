# 📂 Muestra de Datos - P4: Real-World Ingesta Masiva (Supply Chain)

Este directorio está diseñado para almacenar muestras estructuradas del dataset
 original de **DataCo Global Supply Chain**.

## 📊 Especificación de la Muestra

- **Origen:** Dataset público de Kaggle
- **Propósito:** Validación de la ingesta masiva y pruebas de calidad de datos
(DataCo Smart Supply Chain for Big Data Analysis).
- **Estructura del Archivo:** Archivos `.csv` limitados a las primeras 100-500
 filas de prueba para validar el comportamiento del pipeline en entornos locales
 sin comprometer el almacenamiento.
- **Nota de Higiene:** Los datasets completos de más de 100MB se encuentran
 excluidos mediante el `.gitignore` global para mantener la optimización del
 repositorio remoto en GitHub.
