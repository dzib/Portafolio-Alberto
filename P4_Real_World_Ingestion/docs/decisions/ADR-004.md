# ADR-004: Normalización de Datos Históricos con Valores Predeterminados

## Estado

Aceptado

## Contexto

La incorporación de columnas de indicadores con restricciones `DEFAULT` dejó
 registros históricos con valores nulos, afectando el comportamiento de las vistas.

## Decisión

Ejecutar scripts de normalización correctiva posterior (`UPDATE`) para
 homogeneizar los valores nulos en el conjunto de datos existente.

## Consecuencias

Se restauró la precisión en las métricas del dashboard interactivo y se
 eliminaron excepciones por división entre cero.
