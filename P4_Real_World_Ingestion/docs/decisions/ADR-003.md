# ADR-002: Atomicidad Transaccional mediante TRY/CATCH

## Estado

Aceptado

## Contexto

Los flujos ETL pesados requieren mecanismos de seguridad estrictos para evitar
 estados parciales o corruptos ante fallos de nulos.

## Decisión

Implementar bloques atómicos con `BEGIN TRY...CATCH` y control explícito de
 transacciones en los scripts de migración a la capa analítica.

## Consecuencias

Garantiza la consistencia absoluta de los datos y un registro preciso de errores
 en las tablas de auditoría.
