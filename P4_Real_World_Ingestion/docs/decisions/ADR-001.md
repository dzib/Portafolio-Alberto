# ADR-001: Ingesta Masiva de Alto Rendimiento con SQLAlchemy

## Estado

Aceptado

## Contexto

Se requiere procesar más de 180,000 registros de la cadena de suministro global
 hacia SQL Server local sin saturar la memoria RAM.

## Decisión

Utilizar Python 3.13 con SQLAlchemy y la bandera `fast_executemany=True` para
 acelerar las inserciones masivas por lotes.

## Consecuencias

Se alcanzó una tasa de transferencia superior a 23k registros por segundo,
 completando la carga en 7.56 segundos.
