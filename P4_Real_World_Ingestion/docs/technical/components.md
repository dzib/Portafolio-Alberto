# 🧩 Componentes del Módulo - P4_Real_World_Ingestion

- **`02_Ingesta_Pro/02_bulk_load_kaggle.py`**: Script en Python para la ingesta
 masiva optimizada de datasets reales de DataCo Global Supply Chain mediante
 SQLAlchemy y `fast_executemany` (~23.8k reg/seg).
- **`03_Orquestacion_Transacciones/`**: Bloques transaccionales en T-SQL con
 control atómico mediante `BEGIN TRY...CATCH`.
- **`04_ETL_Cleaning/`**: Normalización, estandarización de nulos y resolución
 de anomalías financieras utilizando **T-SQL Dinámico** (`sp_executesql`).
- **`05_BI_Observabilidad/02_Interactive_Dashboard.ipynb`**: Cuaderno Jupyter
 conectado para observabilidad y visualización interactiva mediante PyGWalker.
