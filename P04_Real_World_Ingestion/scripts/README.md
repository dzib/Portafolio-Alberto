# ⚙️ Scripts del Pipeline - P4_Real_World_Ingestion

Índice centralizado de los scripts ejecutados por fases:

1. **Fase 01 (`01_Setup_DDL`)**: Creación de esquemas y base de datos.
2. **Fase 02 (`02_Ingesta_Pro`)**: Carga masiva con Python y SQLAlchemy.
3. **Fase 03 (`03_Orquestacion_Transacciones`)**: Manejo de atomicidad
 con bloques atómicos.
4. **Fase 04 (`04_ETL_Cleaning`)**: Normalización y T-SQL Dinámico.
5. **Fase 05 (`05_BI_Observabilidad`)**: Vistas analíticas y reportes.
