# Arquitectura Física - P4 Supply Chain

- **Motor de Base de Datos:** Instancia local de SQL Server 2025 ejecutándose
 en el entorno de desarrollo.
- **Entorno de Procesamiento:** Python 3.13 desplegado sobre entorno virtual
 localizado en la partición de desarrollo (`D:\Dev\`).
- **Conectividad:** Enlace ODBC Driver 17 for SQL Server.
